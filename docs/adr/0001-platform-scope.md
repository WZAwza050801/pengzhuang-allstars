# ADR-0001 · 平台范围

- 日期：2026-11-17
- 状态：工程实施默认，可凭实测和用户明确要求修订；不冒充平台审核或产品商业批准。
- 影响任务：UI、WEB、WX、APP

## 决策

电脑Web/手机H5先行，微信可玩端采用小游戏；Android/iOS经WebView PoC后交付。普通小程序仅在另行明确需求时承担账号或内容页面。

## 备选与取舍

全平台直接共享DOM不可行；一次重写全部引擎风险过大。共用纯规则、协议、视图模型和tokens，小游戏独立Canvas宿主。

## 验证与修订

WX-02验证真实SDK与双系统；APP-02验证WKWebView/WebView性能；失败以实测重新决策，不空勾。

如果该默认无法通过验证，记录硬件/平台/版本、失败证据、替代项、迁移任务和回滚方法；先更新ADR及依赖，不静默改框架或玩法。
