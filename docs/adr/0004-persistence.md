# ADR-0004 · 持久化与可靠结算

- 日期：2026-11-17
- 状态：工程实施默认，可凭实测和用户明确要求修订；不冒充平台审核或产品商业批准。
- 影响任务：ARC、DAT、NET、OPS

## 决策

PostgreSQL17、pg、版本化SQL迁移；单事务覆盖跨repository；outcome持久化后outbox至少一次投递、幂等效果一次。JSON快照只保留开发兼容。

## 备选与取舍

本地文件不足以支撑跨端资产；先用关系库唯一约束与事务，不引入微服务/Redis作为资产权威。

## 验证与修订

ARC-04用真实独立PG验证事务/并发迁移；NET-04/QA-05验证结算崩溃点与恢复。

如果该默认无法通过验证，记录硬件/平台/版本、失败证据、替代项、迁移任务和回滚方法；先更新ADR及依赖，不静默改框架或玩法。
