# ADR-0002 · 统一身份与会话

- 日期：2026-11-17
- 状态：工程实施默认，可凭实测和用户明确要求修订；不冒充平台审核或产品商业批准。
- 影响任务：ACC、NET、APP、WX

## 决策

自有userId关联邮箱/微信身份；Web refresh为HttpOnly Cookie；App用Keychain/Keystore；微信短期会话可撤销。房间用一次性短时票据。

## 备选与取舍

不能用昵称或seatToken当账号。密码使用成熟Argon2id；JWT校验签名/claims，刷新旋转处理正常并发与重放。

## 验证与修订

ACC真实邮件/平台凭证、撤销、找回、CSRF与重放验收；FND-04配置只是前置，不代表登录已实现。

如果该默认无法通过验证，记录硬件/平台/版本、失败证据、替代项、迁移任务和回滚方法；先更新ADR及依赖，不静默改框架或玩法。
