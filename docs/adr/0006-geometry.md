# ADR-0006 · 几何与资源一致

- 日期：2026-11-17
- 状态：工程实施默认，可凭实测和用户明确要求修订；不冒充平台审核或产品商业批准。
- 影响任务：FLD、AST、BAL

## 决策

data/fields.json是唯一几何来源；120Hz物理与30Hz位置记录保留；侧0/1只变相机，皮肤不能改变碰撞。

## 备选与取舍

大厅等距球场不是比赛物理底图；需要3D表现时也只替换表现，不复制碰撞规则。

## 验证与修订

FLD正逆坐标、两视角、门线/弹簧/高速场景；素材先核对来源再进入可发行包。
