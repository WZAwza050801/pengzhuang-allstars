# ADR-0007 · 运营与发布

- 日期：2026-11-17
- 状态：工程实施默认，可凭实测和用户明确要求修订；不冒充平台审核或产品商业批准。
- 影响任务：ADM、OPS、LIV、REL

## 决策

先非付费闭环；真实资产账本、后台RBAC/审计、可恢复结算、配置版本与回滚先于公开运营；新配置只影响新局。

## 备选与取舍

按钮隐藏不是功能完成；默认不做付费抽卡、现金交易或擅自购买服务。任务清单不自动授权生产发布。

## 验证与修订

REL核实发行主体/区域资质/素材权利；OPS做staging维护drain/恢复；真实公开发布按当时授权执行。

如果该默认无法通过验证，记录硬件/平台/版本、失败证据、替代项、迁移任务和回滚方法；先更新ADR及依赖，不静默改框架或玩法。
