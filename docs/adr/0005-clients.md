# ADR-0005 · 客户端框架与迁移

- 日期：2026-11-17
- 状态：工程实施默认，可凭实测和用户明确要求修订；不冒充平台审核或产品商业批准。
- 影响任务：UI、ARC-03、WX、APP

## 决策

Web采用React19+Vite，保留Canvas2D比赛；微信TypeScript+官方API+Canvas2D；App以Capacitor8.6.2为PoC候选。桌面安装壳由WEB-06按需求选择。

## 备选与取舍

不先引入3D或Cocos重写规则；性能不足先定位资源/宿主瓶颈。React/Capacitor尚未在本任务安装或验收。

## 验证与修订

共享状态机和资源语义，不声称跨端共享DOM；APP/WX的实际兼容与真机验收是后续硬条件。

如果该默认无法通过验证，记录硬件/平台/版本、失败证据、替代项、迁移任务和回滚方法；先更新ADR及依赖，不静默改框架或玩法。
