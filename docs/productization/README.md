# 产品化实施总入口

版本：2026-11-16 / v1。适用仓库：`WZAwza050801/pengzhuang-allstars`。

这是一套供后续 Agent 实施的工程规格，不代表功能已实现，也不保证任何 AI 在缺少设备、平台资格或产品决策时能够无人值守完成发行。目标是把可自动完成的代码任务和必须获得真实证据的任务拆清楚。

## 1. 目标与边界

交付一个具备统一账号、用户云存档、可靠对战结算、运营后台和维护体系的游戏，支持电脑 Web、手机 H5、微信小游戏、Android 与 iOS App。电脑安装包是条件交付项；先评估需求再选择 Tauri/Electron，不默认多维护一种壳。

- 保留现有 5v5、轮流弹射、3 分钟、先进 3 球、20 秒回合、60 秒重连等已确认玩法，变更必须版本化。
- 业务数据跨端统一；画面共享设计规范、资源和视图模型，不假设所有端共享 DOM。
- 微信可玩客户端默认选择**微信小游戏**。普通小程序如有需要，只承担公告、账号服务等页面，另行立项；不把网页嵌入当作小游戏适配完成。
- PC/H5/Android WebView/iOS WKWebView 分别适配和验收。微信 iOS/Android 也分别验收；不以“一套 CSS”替代平台验证，不无理由重写每种系统的全部代码。
- 支付默认关闭。先完成非付费玩法、资产账本和恢复能力；若决定商业化，按 REL-06 的真实渠道要求另行实现和验证。

1. **M0 可重复开发**：FND-01/02/04/05/06、ARC-01/02/03、QA-01。未清点素材前可以本地开发，不得将素材问题当作必须停止所有代码工作的理由。
2. **M1 Web 闭环内测**：ACC-01/02/03/04/06/07、DAT-01/02/03/04/05、NET-01/02/03/04、UI-01/02/03/04/05/06、WEB-01/02、ADM-01/02/03、OPS-01/02/03/04、QA-02/05。允许定向小规模内测，公网或外部试运行还必须通过 REL-01/02 对应渠道要求。
3. **M2 可运营 Web**：补齐 Web、球场/数值/资源验收、匹配、后台、运营功能；通过 QA-01 至 QA-06 与 REL-03。按实际发布范围选择功能开关，不以隐藏按钮冒充已实现。
4. **M3 微信小游戏**：WX 全部 + 对应真机矩阵 + REL-02/04。先 WX-02 技术 PoC，再投入全量重做。
5. **M4 双系统 App**：APP 全部 + 双系统真机矩阵 + REL-02/05。先验证 WebView 性能，再决定壳方案是否继续。
6. **M5 稳定运营**：OPS-05/06、REL-03/04/05、LIV 完成并有运行证据；商业化仅在 REL-06 明确纳入后启用。

以上是交付门槛，不要求所有扩展功能挡住最小 Web 闭环。任务完成与某渠道发布是不同状态。

## 4. 单项任务的标准操作

1. **领取**：选未完成且依赖全部已勾选的任务，在执行记录写 ID、开始时间、分支、起始 SHA。若依赖变更，先更新依赖并说明理由。
2. **读取**：打开任务列明的现有入口、对应专项规范、相关测试。验证实际代码，不能照抄历史结论。
3. **计划**：给出文件列表、接口变化、最小可用实现、必要验证、回滚方式。一般一项一提交或一 PR；不得为凑单项边界留下不可运行状态。
4. **实现**：补齐成功、失败、重试、权限与持久化路径。需新依赖先锁定兼容版本；不要安装 `latest` 后不留锁文件。
5. **验证**：运行任务的验证场景与相关回归；记录命令、环境、通过/失败数量、日志路径。需要真机或平台凭证就如实记录。
6. **复核**：检查接口文档、配置迁移、日志脱敏、前端错误/空态/加载态、资源释放、服务端边界。
7. **勾选**：满足验收后改 `[ ]` 为 `[x]`，执行记录补全证据；运行清单检查器；提交代码、测试、文档和状态。
8. **交接**：记录提交、残留问题与下个依赖已满足任务。只完成部分则保留未勾选，不以“代码写完待测”记作完成。

## 5. 完成定义与产品决策

任务完成至少包括：实现可运行、验证通过、依赖满足、数据兼容、失败路径明确、证据可复查。不得用增加任意数量的测试代替真实行为验收。

本文标为“初始目标”“建议”的指标是待验证预算，不是已经测得的性能或已经确认的经济数值。产品需要做决定时，先用默认方案完成可运行验证；涉及真实价格、原创美术方向、账号供应商、商用渠道等不能凭空替用户定案的内容记入执行记录。没有外部凭证不妨碍本地适配器和契约实现，但不应勾选真实接入验收。

不得随意改变已确认玩法来提高测试通过率。发现规范冲突先按 BASELINE 中的证据优先级处理，修改 ADR/任务后继续可授权的实现。
