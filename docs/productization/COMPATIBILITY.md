# 跨端兼容策略与验收边界

更新：2026-11-18。此策略记录已启用 Web 的实际覆盖与后续端的解除条件；它不是把模拟器或引擎模拟写成真机通过。

## 当前 Web 目标

| 目标                           | 自动化代表用例                                                            | 当前状态                    | 发布判定                                |
| ------------------------------ | ------------------------------------------------------------------------- | --------------------------- | --------------------------------------- |
| Chromium 桌面与移动视口        | 1280×720 DPR 1、390×844 DPR 3；大厅→练习赛→退出；无 console error/warning | Playwright Chromium         | 当前 Web 基线                           |
| Firefox 桌面与移动视口         | 同上                                                                      | Playwright Firefox          | 当前 Web 基线                           |
| WebKit 桌面与移动视口          | 同上                                                                      | Playwright WebKit           | 引擎兼容基线，不等于 iPhone Safari 真机 |
| 响应式布局                     | 320×568 至 1920×1080、软键盘和 1.4 倍字号                                 | WEB-01 Chromium 实测        | 布局基线                                |
| 鼠标、触摸、键盘边界与双方视角 | 真实鼠标、CDP touch、多指/失焦/缩放与双客户端                             | WEB-02 Chromium 实测        | 输入基线                                |
| 弱网、离线与资源恢复           | Chromium 150ms/200KiB/s 首屏；缓存损坏、取消、低清与断图                  | WEB-04/AST-05 Chromium 实测 | Web 资源基线                            |

`npm run test:compatibility` 构建测试客户端，并执行三引擎两视口的代表路径。默认 JSON 仅写入被忽略的 `work/compatibility/browser.json`；任务验收可显式设置 `COMPATIBILITY_REPORT` 留存可复核快照。
