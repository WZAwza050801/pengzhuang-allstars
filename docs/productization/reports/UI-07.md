## 验收方法

真实 PostgreSQL 17.12 与 Mailpit 提供隔离账号、真实 SMTP 验证、持有卡、阵容保存和结算消费者。只在测试准备中生成好友赛结果；该准备夹具不是玩家真实打满一局的证明。普通拖拽、真实触屏与网络比赛另由既有 E2E 和联机回归覆盖。

UI-07 浏览器套件构建独立的正式客户端目录，通过现有 CLIENT_DIR 指定给真实运行时。构建子进程显式 NODE_ENV=production，避免继承测试运行器环境后混入开发句柄，也不覆盖 dist/client。自动化与正式包隔离另由真实 E2E 检查。

全量自动无障碍规则检查使用锁定开发依赖 @axe-core/playwright 4.14.0（锁文件 axe-core 4.14.1），在 Chromium、WebKit 执行 WCAG 2/2.1/2.2 A/AA 标签规则，不禁用规则或重试掩盖失败。Firefox 159 headless 在注入 axe 后偶发原生页面进程崩溃；新页面、DPR1/2、两种执行通道、关闭 JIT、正式构建均曾复现，最小原生表单不复现，内部根因仍未确认。最终不保留这些临时浏览器参数，也不将崩溃算作通过。

Firefox 保留同一构建的全部页面检查，使用明确标识的原生 DOM 语义检查（语言、单一 main/h1、控件名称、图片名称、重复 ID），并执行完整视口、键盘、弹窗和比赛操作。它不等价于 axe 全规则通过。自动扫描范围和此工具兼容性限制单列，不能由此宣称全 WCAG、所有屏幕阅读器或真实设备已获认证。
