# FND-06 · 范围和架构决策

日期：2026-11-17。已建立 [ADR 索引](../../adr/README.md) 及 ADR-0001 至 0008。

- 平台：Web/H5先行，微信小游戏独立宿主，Android/iOS先通过WebView PoC。
- 认证：自有userId、多provider绑定，Web Cookie、原生安全存储，短时房间票据。
- 公平：练习、均衡好友、排位、成长模式分开，不将客户端自选等级当持有权。
- 数据：PostgreSQL17、参数化SQL、事务、唯一约束、持久outcome及幂等结算。
- 客户端：React/Canvas增量，Capacitor8候选；不先重写引擎。
- 几何：单一来源、皮肤不改碰撞、侧别只影响相机。
- 发布：非付费默认，配置版本/回滚、后台审计及恢复先于公开运营。
- 依赖：精确锁定和分任务兼容验证，记录与初始候选的差异。

待外部提供的项目：素材权利凭据、发行主体/渠道资质、邮件和微信真实账号凭证、原生签名身份、真机、商业化决定及最终原创美术方向。没有假设这些已获得；它们不阻止当前基础模块编码。

验证：ADR编号唯一，索引链接存在，逐项与架构规范/领域契约/任务编号交叉检查；均明确默认方案、取舍、验收和失败后的修订方式。纯决策文档未重复运行全套游戏测试。
