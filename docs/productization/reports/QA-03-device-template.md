# QA-03 · 真机验收记录模板

一份记录只对应一个设备和一个构建。`状态` 只能填写：`通过`、`失败`、`阻塞`、`未测`；模拟器和 Playwright 引擎不可填写为真机通过。

| 字段                                                                | 值  |
| ------------------------------------------------------------------- | --- |
| 日期与执行人                                                        |     |
| 端（iPhone Safari / iOS App / Android Chrome / Android App / 微信） |     |
| 设备型号、系统与浏览器/微信/WebView 版本                            |     |
| App/小游戏/Web build SHA 与资源版本                                 |     |
| 网络（Wi-Fi / 蜂窝 / 弱网配置）                                     |     |
| 测试账号/房间（不得记录 token、密码或验证码）                       |     |

| 用例                                              | 状态 | 证据与缺陷号 |
| ------------------------------------------------- | ---- | ------------ |
| 冷启进入大厅；320/390 等实际安全区无裁切          | 未测 |              |
| 文本输入与软键盘不遮挡提交；系统返回/导航正确     | 未测 |              |
| 本地练习鼠标/触摸瞄准、弧线、取消与退出           | 未测 |              |
| 双端房间开局、对方视角、出手与重连                | 未测 |              |
| 后台/前台、锁屏或来电后不误发球且以服务端状态恢复 | 未测 |              |
| Wi-Fi/蜂窝切换、弱网、离线与资源缓存损坏恢复      | 未测 |              |
| 连续进入退出 10 局，无明显泄漏/崩溃/音频残留      | 未测 |              |

结论：仅当本表全部必需项有物理设备证据时，才可在对应 WX/APP 任务中标记真机验收通过。
