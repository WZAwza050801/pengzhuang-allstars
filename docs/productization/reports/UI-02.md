# UI-02 · Web 页面壳和状态机

起始提交 `632693c`。默认入口现由 React 19 和 React Router 7 承载；桌面使用左侧主导航，移动端使用底部导航并应用安全区与 `dvh`。匿名访客可直接开始本地练习；账号、持有卡、房间和线上对局不会以本地演示值伪造。

`client-model` 提供仅接受内部导航意图的 Web 路径映射，以及带 generation 的视图请求状态机：旧异步结果、失败和取消不会覆盖后来的页面。`PracticeMatchScreen` 经既有 `HostBridge` 创建 `GameView`，并在 Effect 清理时停止请求、销毁 Canvas 宿主、订阅、音频与本地 Host。开发期 StrictMode 的重复挂载也走同一清理路径。保留 `?legacy=1` 兼容入口，供既有 Demo 浏览器回归继续覆盖。

验证通过：

- 完整 `npm run check`（100 单元、5 契约）与完整 `npm run build`；
- `vitest` 导航和 web-shell 状态转移共 7 项；
- `npm run test:web-shell`：Chromium 1280、390、320 三个视口均无横向溢出；关闭功能提示正确；连续两次进入练习再退出后无 `.game` 或 `window.__pz` 残留；注入一次 Canvas 挂载失败后重试成功，0 控制台错误。结果见 [UI-02-browser.json](UI-02-browser.json)；
- `npm run test:e2e`：16/16 通过，含现有 Canvas 出手、触屏弧线、前后台、画质、资源预算、双端好友赛与宿主释放。

构建时 React Router 与 Zod 的上游 Rollup 注释/`use client` 提示仍会输出，但不影响构建成功；本任务未修改其依赖源码。真实账号大厅、房间、服务端比赛票据和结算由其依赖任务继续实现。
