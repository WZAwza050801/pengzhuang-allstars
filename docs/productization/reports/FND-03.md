## 来源核对和待替换清单

| 分类 | 来源入口 | 发行前动作 |
|---|---|---|
| 原版 UI / 头像 / 技能 / 场景 | materials 来源材料、extract/import/build 脚本、portrait_map | 获得可核实授权或替换原创资源 |
| 原图/抠图/手绘及 AI 历史产物 | art/raw、历史 art-pipeline、settings、portraits.ts | 确认创作者/生成服务使用条件及二次创作范围，缺证据保持未核实 |
| 游戏定义和恢复数据 | per-file source、roster-provenance、资料包 | 逐类确认来源和可分发范围，不能把原始资料复制当授权 |
| 原创工具和重建代码 | 仓库脚本，仓库未声明许可证 | 由权利人决定项目许可证及分发范围 |
