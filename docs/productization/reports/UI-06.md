五条真实页面链路：暂停消费者后结果页等待入账、刷新仍是原比赛、重复查询不新建结算；恢复消费后完成，断网仍能从本会话已读记录回到原结果；恢复网络/刷新后按原 matchId 查询。重复“再来一局”不发创建请求，后续双击创建只有一张票据和一个新房间。终局广播丢失时通过已结束房间状态进入原结果，原房间拒绝重入并链接本人记录。

正数奖励与流水由真实数据库资产事务准备：实际金币 +50、余额 350、本人关联流水一致；注入结果查询 503 后保留 +50，不显示零或再次发奖。外人/错误账号提示/查询注入/撤销会话拒绝读取。记录页真实查询 23 场并分页 20+3；320/768/1440 无横向溢出，320 大字号仍可键盘操作新局。另一条链路延迟实际服务器的旧账号响应，切换 Cookie 和 session 后再释放，旧奖励不能进入新账号页面。

用于正数奖励/分页的组件准备夹具通过真实结算消费者和 SQL 排名事务标记生成记录；标记不等于 Elo，也没有生产绑定。生产仍只开放好友赛；好友赛明确不计排位，其他记录的积分显示尚未确认，不虚构零变更。真实排名仍归 MM-02。

离线副本仅在已确认登录的当前运行会话中可用，最多 32 场，退出/换号/账号拒绝/卸载立即清除，不写磁盘或浏览器持久存储。刷新在联网确认账号后重新读原结果；不声称冷启动离线可恢复未读数据。没有保存长期票据、重连凭据或 RNG 到普通页面。
