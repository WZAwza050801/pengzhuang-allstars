# QA-03 · 跨端兼容与真机矩阵

当前 Web 代表路径已在 Playwright Chromium 159.0.8154.6、Firefox 159.0、WebKit 27.2 运行：每个引擎覆盖桌面 1280×720 DPR 1 与移动 390×844 DPR 3，执行大厅进入练习赛、等待 Canvas、打开菜单并退出大厅。6/6 通过，详细环境和每项结果在 [browser.json](QA-03/browser.json)。

所有页面 error 列表为空。Firefox 移动模拟器记录了一条 `chrome://juggler` 自动化内部“布局过早”warning；它不来自页面 URL，已在 JSON 中单独保留，未被当作项目页面 warning 忽略。

[兼容策略](../COMPATIBILITY.md) 合并了 WEB-01 响应式视口、WEB-02 输入与 WEB-04 弱网证据，并严格区分引擎模拟与真机。iPhone Safari/iOS WebView、Android Chrome/WebView、微信和 App 都没有在本任务标记通过；后续执行人须使用 [设备记录模板](QA-03-device-template.md) 填写真实机型、系统、构建版本和全流程证据。

日常运行 `npm run test:compatibility` 的结果只写入忽略目录 `work/compatibility/browser.json`，避免污染任务证据。需要更新本报告的可复核快照时，PowerShell 使用 `$env:COMPATIBILITY_REPORT='docs/productization/reports/QA-03/browser.json'; npm run test:compatibility`。
