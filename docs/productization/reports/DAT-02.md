并发 PATCH 同一资料版本只有一项成功、另一项 409；等级、exp、资产和角色不接受客户端修改，他人目标/未知分页/危险昵称/外部或未知头像拒绝。合法引号昵称以 SQL 参数安全保存。复查补充大版本号用例，先复现 PostgreSQL int 转换产生 500，再将公共 revision 上限对齐 int32，最终 400；全量 96 项通过。资料 level/exp/钱包不受昵称更新影响。

封禁、等待注销及已注销状态均拒绝初始化；实际到期去标识删除 profile 后保留初始化回执/账本和默认阵容外键，不复活存档。微信登录初始化的上游使用受控契约替身，同一身份两次不同 code 不重复授予；真实平台仍由 ACC-05 验收，本报告不替代。
