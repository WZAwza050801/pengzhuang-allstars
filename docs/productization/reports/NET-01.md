签发在同一事务冻结五张合法持有卡及阵容/模式/数据版本，写 60 秒一次性随机 nonce 的 hash。真实 SQL 并发消费及两个独立 service 实例只成功一次；真实 WebSocket 并发重放也只进入一次。不同房/模式/配置不会烧掉合法票据，过期不能入局。签发后封禁、撤销/过期会话或禁用卡牌均在消费处拒绝；失败回滚 consumed_at。数据库 INSERT/UPDATE 触发器注入故障返回固定安全错误，移除故障后可重试，没有部分写入。

真实双账号 SDK 使用服务端 profile，两个相同昵称仍占两个不同账号席位；消息仅给本人身份，不公开对方账号/持有卡 UUID或旧 seatToken。伪造 userId、旧座位 token、直接建账号房与 set_lineup 均拒绝。第三账号在房满前取得的旧票据不能后来挤入；新票据可替换本账号在线连接，不影响对手。断线后同进程新票据仍回原席位，撤销会话后再入拒绝；生产 startRuntime 接线实际验证。

成长模式读取持有等级，均衡好友赛读取 Lv5；票据之后升级卡牌不改变原快照，新票据才读取新等级。正式玩法的客户端入口、刷新/跨进程恢复和持久结算留给 UI-05、NET-03/04/05，本轮不冒充完成奖励或排位。

单个运行时的所有房间共用 HTTP/WS 准入预算；真实低预算 HTTP 验证建房跨房限流，伪造转发 IP 无效，WebSocket 与 HTTP 共享预算，URL 令牌和超大入场正文拒绝。12 张/账号/分钟签发预算由数据库用户锁保证；房间目录和 IP 桶均有上限。多个运行时的网关全局容量属于后续 OPS/QA。

首轮验收纠正了测试夹具未填写封禁时间/会话创建时间约束、满员房间阻止合法换连接、批量协议测试触发新增生产限流、回滚断言仍指上一迁移，以及新 HTTP 准入层遗漏 Colyseus 既有 CORS 响应头。保留生产限流默认，批量协议夹具显式提高其预算，独立准入测试验证真实限制；恢复原 CORS 策略并增加回归断言。验收以最终复验结果为准。

迁移回滚测试最终改为比较数据库的实际迁移序列、回退一项并重新应用，避免每次新增迁移都要改写固定表名；重放真实 DDL 仍须成功。完整 173 项验证后，该通用回滚测试再以隔离 PostgreSQL 定向复验。

无新增依赖，不改物理/场地/经济/模式规则。新增迁移只保存票据 hash 和服务器阵容快照；不保存凭据原文，不向日志写入令牌。真机与真实微信凭据仍按原记录暂缓，素材权利、依赖审计和平衡放量门槛继续保留。
