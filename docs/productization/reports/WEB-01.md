# WEB-01 · 响应式 Web 大厅

React Web 大厅现在在桌面端提供左侧主导航、中央本地练习球场和右侧辅助信息；右侧只说明已落地的本地规则与尚未接入的云端区域，不用演示数据冒充真实账号、资产或公告。移动端保留顶部状态和底部主导航，内容区独立滚动。

应用壳以 `visualViewport` 高度更新 `--web-viewport-height`，并将安全区、`dvh` 回退、大字体比例和软键盘收缩纳入同一网格。球场预览是大厅图片，不修改既有 Canvas `GameView` 的几何或物理参数。可选提示拥有稳定网格占位，避免它缺席时内容区挤掉底部导航。

浏览器验收结果见 [browser.json](web-01/browser.json) 和同目录截图：

- 320x568、360x800、390x844、430x932、768x1024、1280x720、1440x900、1920x1080：无横向溢出，主操作、球场预览和导航均可见；辅助面板只在 >=1024px 显示；
- 390x844 的 1.4 倍字体：主操作仍可见且无横向溢出；
- 390px 宽、420px 高的软键盘可见视口：主操作底部为 257.09px、主导航底部为 395px，均未被遮挡；
- 所有矩阵视口 0 条 console error。

验证通过：

- `npm run test:web-layout`；
- `npm run test:web-shell`；
- `npm run check`（100 单元、5 契约）；
- `npm run build`；
- `npm run test:e2e`（16/16）。

生产构建仍有既有的 Rollup 第三方注释/`use client` 提示，以及一个大于 500 kB 的遗留代码块提示；本任务未引入构建失败或新的浏览器错误。
