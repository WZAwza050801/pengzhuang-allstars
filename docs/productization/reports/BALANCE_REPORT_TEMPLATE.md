# 平衡实验报告模板

提交与环境：Node/引擎/平台/硬件、输入版本和 SHA256、运行命令。

固定输入：双方阵容、等级、模式、seed 全集、先手交换方式、AI 算法及候选/时间预算、时钟语义。明确哪些是实验假设，哪些是生产规则。

原始证据：每场 seed/先手/比分/终止原因/杆数/技能次数/每杆状态 trace hash；配置差异文件、原始行总 hash、独立回放样本及结果。

统计：胜/平/负、双方先手得分率、样本量、区间方法与假设、保险上限/异常比例；保留不利结果，不以挑选 seed 替代修复。

敏感性：一次改一个参数并记录版本化差异；各卡组/等级/技能/AI 预算与经济 7/30 天结果分别列明样本和局限。

结论：报告有效性与发布门槛分别判定；AI 代理不代表真人结论。失败时记录原因与后续实验，不为了绿灯改动已确认规则。

发布与回滚：旧版保留位置、完整门槛、灰度分组/观察指标、停止条件、回滚版本、旧局处理、历史回放及业务数据纠正策略。未经实际运行的验证明确标注未执行。
