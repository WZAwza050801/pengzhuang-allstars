# 产品化任务清单

初版：2026-11-16；18 个工作包、112 项任务。复选框是任务完成状态唯一来源。初始全部未完成，当前进度以各项复选框为准；已有 Demo 代码也要按新验收补强后才能勾选。

先阅读 [总入口](README.md)、[执行记录](EXECUTION_LOG.md) 和 [完成标准](README.md#5-完成定义与产品决策)。实施顺序以依赖为准；前置任务未完成不应勾选后置任务。引用的 apps/packages 等是目标路径，当前不存在的脚本须在相应实现任务中创建真实 runner，不能把缺脚本当成功。

统一操作：核实输入 → 记录领取 → 增量实现 → 验证成功/失败/重试/权限 → 更新文档和证据 → 勾选 → 运行 `node tools/check-plan.mjs` → 提交。外部条件缺失时保持未勾选，记录阻塞并继续可独立完成的授权任务。

任务规模过大时可拆稳定新 ID，并同步依赖、总数与规范；不能通过删验收缩小范围。任务列“验证”是必须覆盖的行为，具体报告记录实际命令/环境/结果。
