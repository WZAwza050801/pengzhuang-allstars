# 账号好友房与比赛界面

UI-05 使用 `/room/:code?` 承担建房、邀请、准备和全屏比赛。它连接 [NET-01 账号票据](account-rooms.md)，复用 OnlineHost、GameView、HostBridge、既有 Canvas/物理/输入，不复制第二套弹射规则。旧 `?legacy=1` 游客试玩继续独立存在，不获得账号、成长或奖励权限。

## 入口和真实能力

`friendRoomsEnabled` 是 `/auth/options` 的新增能力字段，缺省 false；runtime 仅在真实票据服务可用时开启。Web 导航同时检查账号、inventory、网络和公共服务状态。`/config/manifest` 只在具备账号房且非维护时增加 friend；未实现的 ranked/growth 客户端入口保持关闭。维护状态还在票据 API 服务端拒绝新建/入场，不能只禁用按钮。

未登录邀请只保存内部 `{page: room, code}` 意图。真实登录完成或有效会话恢复后，校验内部意图再回跳，不接受任意外部 URL。页面加载只读当前用户的云阵容/卡牌；用户选择完整有效的持有阵容、明确创建或加入后才 POST 票据。用户可刷新读取和去阵容页调整；失败不会自动创建第二间房。

邀请链接只含公开六位房间码；页面可自动复制或提供只读文本手动复制。票据、长期凭据与旧 seatToken 均不出现在邀请、路由或普通偏好中。双方昵称、持有卡定义及 Lv5 摘要取服务端快照，入场后不上传阵容/等级变更。准备/取消等待服务端回执，双方准备才由服务器开局；对手离开后显示等待状态。

## Host 与视图生命周期

OnlineHost 的 account port 使用 WebAccountClient 签发票据，再以 `{protocol,ticket}` 加入指定房间；消费后验证返回账号和规则版本。每次重连重新取票，不走游客 seatToken 或旧 transport token 后门。停止或换账号后，迟到票据不能再加入；已经迟到建立的连接立即离开。旧连接的消息回调检查当前 Room 引用，不覆盖替换后的状态。

RoomPage 按 userId/sessionId 独立持有 Host；GameView 通过 `hostLifetime: owner` 借用，StrictMode 重挂载或重试画面只释放视图资源，不误关账号连接。离开页面/切号由 owner 关闭 Host，清定时器和回调。已知房间码的同账号手动重入收到首个 resume 时也会挂载比赛，并只替换本人的旧连接。

这不等于 NET-03：没有 active-match 自动发现、阵容已更新后的通用刷新恢复、跨进程参与关系或重启接管。重入仍须满足 NET-01 的原阵容 revision/窗口约束。当前缺少这些能力时不承诺杀进程后自动回局。

## 输入、时钟和状态

NET-02 为账号连接增加协议 2/revision 和有界回放，旧状态不回退当前局面；收到 ACK 但漏回放时只重新同步。消息顺序与回执定义见 [match-protocol.md](match-protocol.md)。

账号比赛移除大厅导航覆盖，复用原鼠标反向拉线、方向键弧线、触屏弯曲手势和 side 1 相机。比分明确标注我方/对方；HUD 区分本方回合、对方回合、待确认、播放、恢复中、断线和结束。发出意图时立即锁定重复出手；只在服务端出手/状态/错误或恢复后解除，不自动补发未知出手。手动“重新同步”也只换票读取原比赛，不重发出手。

本方断线/账号确认中禁用输入；对手断线显示来自房间快照的剩余窗口，既有服务端时钟继续走。倒计时只是显示，到零等待服务端换手，不在浏览器判超时或胜负。公共维护/新配置限制新操作；已经冻结规则的比赛可继续，不把公告当作暂停裁判。

菜单支持音量、静音、画质和皮肤；音量通过真实 WebAudio 主 Gain 调整，仅保存本地偏好。后台按既有生命周期暂停表现/音频，恢复重建权威状态而不补播旧动画。菜单管理焦点和 Escape/Tab；返回大厅确认说明断线后果，认输只发意图，结果等待服务端。刷新/关页的浏览器原生提示可因平台策略而异；没有客户端认输回执不能视作服务端认输。

结算画面只展示服务端结束状态及无排位/无正式奖励提示，不显示假余额或假入账。可靠战绩/奖励和正式结算页仍由 NET-04/UI-06 实施。

## 验收与资源

真实 PostgreSQL/会话与两个 Chromium 上下文验证邀请、准备、双方输入、超时、断线、切号和权限。延迟出手回包使用真实服务端 `raw` 投递缓冲，不替换比赛计算；触屏使用 CDP 实际事件、完整弯曲路径并等待画面/账号可操作。维护公告的客户端状态切换是明确的响应注入；服务端维护拒绝另有真实 API/数据库测试。

320/768/1440 宽度逐个球员位置使用 DOM 命中检查，鼠标/触屏路径复用 FLD/BAL 几何。截图是浏览器证据，不替代 iPhone/Android/微信真机。音量源变更重新导出 UI pack、目录、包清单、审计和 readiness；资源权利与物理/经济配置没有改变。证据见 [UI-05 报告](../productization/reports/UI-05.md)。
