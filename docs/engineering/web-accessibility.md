# Web 页面状态与操作约定

UI-07 覆盖当前开放的 Web 功能。微信小游戏、原生 App、设备听感与真实触屏生命周期另按对应平台任务验收；浏览器引擎检查不替代真机。

## 组件与焦点

- 正常页面有主标题、主导航和跳到主要内容的链接。切页时重置内容滚动并聚焦新标题；延迟加载完成后再聚焦，卸载立即停止观察，迟到响应不能带回旧页面。
- 输入框使用原生标签、输入类型、自动填充和约束。提交使用表单，忙碌时禁用重复操作，错误/完成说明通过状态区告知；注册表单移除后聚焦完成说明。
- 比赛菜单、辅助出手和终局结果具备具名 dialog、aria-modal、Tab/Shift+Tab 循环、Esc 关闭和关闭后返回菜单按钮的焦点。弹窗外的比赛内容 inert；关闭结果后可从菜单重新打开。
- 比赛比分、当前回合和回合计数提供 DOM 文字；Canvas 有用途说明。辅助出手允许选择己方可用球员、按当前视角设置方向/力度/弧线，仍提交既有 ShotInput，继续经过原本的回合、连接、冷却及服务端校验。0°向上、90°向右，另一侧视角同时翻转两轴。
- 不暂停权威计时，不改场地、物理或收益。辅助出手在非己方回合、回放、断线恢复或终局时不可提交；菜单中说明比赛继续计时。文本输入聚焦时不会触发弧线快捷键。
- 原生控件与独立主操作至少 44 CSS px；复选框可与关联标签合计形成触控区。正文内的链接仍保留文本链接形式。焦点使用既有 tokens 的可见轮廓。
- 设置允许 100/125/150/200% 文字大小和始终减少动画，仅持久化这两个白名单显示偏好到本机。保存被拒绝时保留当前运行页面的内存设置并明确提示，重新加载不承诺恢复；不据此读取或写入业务数据。
- 同时尊重系统 prefers-reduced-motion 和手动设置。减少过场、拖尾、重定位和插值表现，直接显示已经计算完成的权威结果；比赛规则、出手和计时仍保持原值。
- 页面与面板可滚动，窄屏大字允许控件换行。全局视口允许浏览器缩放。球场保留二维几何比例，菜单/表单另行适配；不把整页横向溢出解释为球场例外。

弹窗行为依据 [WAI-ARIA APG 对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)，重排范围参考 [WCAG 2.2 Reflow 说明](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)。这些是实现和检查依据，不构成全 WCAG 或所有辅助技术的认证。

## 页面状态矩阵

| 页面/入口 | 加载、空与正常 | 错误/离线与恢复 | 主要操作边界 |
|---|---|---|---|
| 大厅 `/` | 公共规则/公告与本人余额独立读取；空公告有说明，访客有练习入口 | 维护/旧版本/离线可识别，规则可重读；余额未知不伪造为零 | 未开放模式明确关闭；未预载的练习资源在离线时禁入并说明 |
| 登录/注册 | 原生邮箱/密码/昵称，处理中锁定提交；注册完成状态 | 可辨识网络/权限/频率错误，可重试；本地练习可达 | 不存明文密码/票据，不以注册响应披露邮箱是否已存在 |
| 找回/重发邮件 | 邮箱输入、提交/处理中/收到申请 | 网络失败保留可重试入口；真实 SMTP 用隔离收件箱验收 | 不将申请成功等同验证或重置成功 |
| 验证/重置/绑定链接 | 链接先从地址栏移除，再显式确认 | 缺失/过期/复用链接有说明与重新申请入口 | 邮件链接不进入反馈内容，不自动合并身份 |
| 我的/设备/账号操作 | 会话恢复、身份与设备列表分别处理 | 会话失效转登录，退出结果待确认时保持对应状态；操作错误留说明 | 敏感动作保持重验证，跨账号响应不混入页面 |
| 注销查询/取消 | 显式查询与当前注销状态 | 失败/失效不显示成功，可回登录或重试 | 不因页面打开自动提交注销 |
| 持有卡/阵容 | 读取状态、空云端阵容、五卡草稿、保存状态分别显示 | 余额未知/升级未确认/并发版本冲突有说明；保留草稿，原记录确认 | 真实持有卡与服务器版本；离线禁写，仍可回主导航 |
| 好友房 `/room` | 读取真实阵容、创建/加入状态、准备/取消准备 | 非法/过期/满员/断线有提示和回退；调整阵容是可触控链接 | 双击不新建两房，不从 URL 提取座位或账号凭据 |
| 账号比赛 | 挂载与恢复、当前权威比分/回合、待确认出手 | 断线恢复限制输入；离开说明继续计时；终局可查原结果 | 键盘/触控共享 ShotInput 与服务端规则 |
| 本地练习 | 延迟加载、真实本地 AI 和物理、菜单、辅助出手 | 挂载失败显示重试/返回，退出清理画布/监听器 | 不读写账号奖励；练习加载/返回属于真实主流程 |
| 终局弹窗 | 比分、原因与结果/回大厅按钮 | Esc 可关闭并从菜单重新查看 | 本地练习不伪造账号结算；账号结果查询指向原 matchId |
| 本人记录 `/results` | 读取、无记录、分页、已确认记录 | 查询失败有 alert 和重试；运行会话离线只看已读副本 | 仅本人；退出/换号清缓存，不落磁盘 |
| 结果 `/result/:id` | 保存/待入账/已结算分开，实际奖励/本人流水 | 失败不合成为零，可重查原比赛；离线明确副本边界 | 再来一局进入新房设置，查询不重复发奖；非法 ID/非参赛者拒绝 |
| 显示设置 `/settings` | 字号和减少动画的当前值/保存状态 | 存储拒绝时当次生效并说明；可回大厅/帮助 | 白名单本机显示偏好，无资产/等级/角色字段 |
| 问题与反馈 `/help` | 手动描述、生成说明、复制状态 | 断网可生成；自动复制被拒绝则聚焦可手动复制的文本框 | 仅生成本地草稿，明确尚未发送；没有后台工单或自动上传 |
| 成长/俱乐部等未来入口 | 按实际开关显示关闭/受限状态 | 可返回主导航；登录门禁沿用路由决策 | 不把说明页当已实现玩法或社交功能 |
| 未知路由 | 返回大厅 | 不产生无出口空白页 | 不根据任意 URL 放行远程对局 |
| 页面渲染/延迟模块异常 | ViewBoundary 接住页面异常并聚焦恢复标题 | 返回大厅、帮助或完整重载；初始应用模块失败也有原生 DOM 恢复面板 | 异常仅输出固定诊断，避免把原始异常/凭据打到生产控制台 |

## 反馈与检查范围

反馈只收集路由类别、网络、服务状态、时间与用户主动填写的最多 1000 字说明。自动部分不读账号、浏览器存储、完整 URL、参数、hash、比赛 ID 或凭据。用户自行将草稿发送给测试版本提供者，页面不会声称已受理或已发给维护人员。

自动检查使用锁定的开发依赖 @axe-core/playwright 4.14.0，按照 [官方 Playwright 接口](https://github.com/dequelabs/axe-core-npm/blob/develop/packages/playwright/README.md) 实际运行。规则结果、需要人工判断的 incomplete 项、窄屏/大字的布局问题与交互场景分别记录。自动无违规不等于屏幕阅读器、原生软键盘或真实设备全部通过。当前完整证据、执行数量及限制见 [UI-07 验收报告](../productization/reports/UI-07.md)。
