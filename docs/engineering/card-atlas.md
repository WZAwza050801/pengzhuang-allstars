# 球员卡、头像和图集规格

`npm run cards:atlas` 从当前 117 名球员的 ID、姓名、位置、品质生成资源；`npm run check:cards` 验证来源输入、生成器 hash、映射、PNG hash/字节数/尺寸、完整内容版本。重复导出同一输入不会重复写相同 PNG；版本由内容决定，没有时间戳。导出需要项目版本的 Playwright Chromium。

主资源为 `client/public/assets/cards/atlas.json` 和三张 PNG；别名由总资源目录绑定。`CardAtlasSchema` 拒绝错人/重复身份、越界、重叠、缺页、未用页、不安全路径、缺状态和超 2048px 页面。生成器和客户端不读取原始 materials 路径。

| 项目 | 规格 |
|---|---|
| 头像区域 | 128×128 px，圆形内容框，中心锚点 (0.5, 0.5) |
| 卡框区域 | 160×224 px，纵横比 5:7，中心锚点 (0.5, 0.5) |
| 留边 | 每边 2 px，复制自身边缘/角像素；采样源矩形不包含留边 |
| 头像页 | 1056×1056、1056×924，按稳定球员 ID 顺序分块 |
| 卡框页 | 656×912，五品质 × 正常/选中/禁用，共 15 个可复用框 |
| 卡片内头像 | 逻辑矩形 x=16、y=10、128×128；不做非等比拉伸 |
| 动态文字 | 名字 y=165；位置/状态 y=199；随 DPR 绘制，长名降字号后省略 |
| 当前图片总量 | 654,968 B；解码 RGBA 约 10.26 MiB，不含 DOM/画布与旧资源 |

品质色取项目现有白/绿/蓝/紫/橙语义。选中还有勾，禁用还有锁及文本，不能只靠颜色。名字、等级、位置与可本地化按钮文字不烘焙进 PNG。`drawPlayerCard` 复用图集并动态绘制文字，`loadCardPages` 在解码后核对尺寸，错误可由宿主展示重试。

品质与原始稀有度分开：边框使用原有 quality，角标显示数据中的 rarity（含 9）；没有来源值时显示 `?` 并提供“稀有度未知”的可访问名称，不按品质编造稀有度。映射 JSON 作为总资源目录的 data 条目参与 hash 与版本计算，`card.atlas` 别名指向它；修改姓名、稀有度或裁切映射同样会使缓存版本更新。

原创占位由 `tools/card-textures.mjs` 的几何路径独立绘制；不采样原版头像/标志，也不宣称真实球员相貌。球衣几何标记按稳定 ID 区分，身份名称/位置来自数据，不编造人物。来源策略单列 rebuilt-card-atlas；商业发行仍按 REL-01 核实，未自动把授权状态改成已批准。旧 Demo 的原版头像入口保留，本项为新组件和后续替换提供占位资源，不声称已替换整个游戏。

`npm run test:cards-browser` 启动独立本地验收页 `/card-debug.html`：全卡联系表、15 种卡框、品质筛选、选中/禁用、键盘焦点、加载失败后重试。测试解码全部 117 张旧头像，核对新图集 528 个边缘采样，并在 DPR 1/2/3 实测。截图及浏览器记录位于 `docs/productization/reports/card-atlas/`。验收页和审计句柄只用于开发，不作为生产入口。

本项完成资源规格与可加载验收；按场景预载、取消、缓存、发布过滤以及原版资源最终替换由 AST-05/REL-01 承接。这里没有将占位图称作最终美术，也没有把 Web DPR 检查冒充微信或 App 真机验收。
