# LB-1b 比赛场景按原版整屏铺满 · DONE 2026-11-16

## 为什么做
安安反馈"竞技场的背景做得不太好"。原来只把 Scenes_xx.jpg 裁成两条球门线之间的草地（956×1559 px），四周是程序画的橙黄墙加深绿底，比分栏浮在场地外面。
原版是整张 1440×1920 的场景：两侧红蓝看台，白石墙，四角弹簧，树篱，顶部还有蓝黑红比分条。

## 做了什么
- `art/build_field_skins.py`：额外导出整张原图 `client/public/assets/fields/scene_0X_full.webp`（1440×1920，每张约 170–200 KB）。
- `data/fields.json`：五个 scene 皮肤新增 `scene`、`sceneSize` 两个字段，并更新了 desc。`geometry` 没动，dataVersion 不变。
- `client/src/render.ts`：
  - 用 `artCrop` 把整张原图放进世界坐标：一个原图像素等于 6.0/956 m，裁剪框正好落在物理矩形上，物理碰撞完全不变。
  - 原图始终不随视角翻转。图在球场中心处是对称的，只有看台和比分条不对称，所以联机时红方看到的比分条也在上方。
  - 有整图时，不再画程序墙、门口石块和程序草地。球门里那层很淡的网和门线保留。
  - 四角弹簧静止时直接用原图，只有被撞时才叠上回弹动画。
  - 布局：整图顶端（比分条）贴住画布顶部，宽度刚好露出白墙和看台内沿，下方球门不会被底栏挡住。比原图高的屏幕，在原图下面补一块深色底板，底栏放在上面。
  - 新增 `sceneBar()`，返回比分条在屏幕上的位置。原图里比分条的范围是 x 240–1210、y 0–100 px，五张实测一致。
- `client/src/game.ts` 和 `style.css`：
  - 场景模式下给 `.game` 加上 `.scene`，画布铺满整个比赛区。
  - 比分栏叠到原图比分条上：左边青色区是我方名字和比分，中间黑色区是比赛计时和回合秒数，右边红色区是对手。轮到谁，谁的名字就变黄并加箭头。"你的回合"提示放在比分条下方。
  - 菜单按钮改用 Btn_02。原来的 Btn_Return 是一个箭头图，文字压在上面。
- `tools/shot-skins.mjs`：可以用 SHOT_W、SHOT_H、SHOT_TAG 指定手机尺寸截图。
