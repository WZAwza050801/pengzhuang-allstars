## 画面怎样组起来

从后往前：场地底图 → 球门装饰 → 棋子阴影／队色底盘 → 头像 → 足球 → 瞄准线与力度／弧线控件 → 技能与进球特效 → 顶部比分和回合提示。

比赛边界、门柱和门线用独立几何配置，不从背景图片的边框自动当作碰撞墙。实施时由AI标出有效草地矩形、门口和门线，与截图叠加核对后输出`field_geometry.json`。换皮肤时继续使用同一份碰撞几何。

## 用户自己批量重绘头像

1. 读取02目录`generation_jobs.jsonl`；106行分别含姓名、原头像参考路径、目标文件名与完整提示词。
2. 使用每行`reference_image`，很多球员优先用1.2.0版较丰富的头像。人物身份以原表为准，不用球星近期照片覆盖十年前的造型。
3. 生成512×512透明PNG，头发与耳朵完整，只画头部。文件名保持`head_1001_10102.png`这类headIcon键。
4. 新图放新建的`generated_portraits/`，保留原图。用`portrait_style=original|redrawn`切换；原始头像194×188和新图512×512分别配置显示留白，不能横向拉伸。
5. 收到新图后由开发AI检查透明通道、边距、朝向、身份和文件名，再接入素材清单。小罗候选未确认前不进入正式批次，卡队没有原头像可供参考。

`generation_prompt_template.txt`是通用模板；逐人提示词已经带有对应文件名和参考版本。新生成图一律标“重绘”，不声称为原版。

## 球场重绘提示词模板

> 参考附带《碰撞全明星》球场原图，重绘一张竖屏、俯视、卡通桌面弹射足球场。严格保持场地有效区域、两端球门中心、门口宽度与中线／中圈的相对位置；红蓝双方方向清晰，草地与边框材质层次明确。画面中不含球员、足球、计时、比分、按钮、文字或水印。边界不要遮挡有效游戏区域。输出完整场地背景。几何尺寸由随附field_geometry配置决定，装饰不得改变碰撞边界。

这是重绘建议，不是精确几何还原结果。开发AI应先确定比例，再批量生成，避免每张皮肤重新调碰撞。
