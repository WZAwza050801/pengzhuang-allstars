# 玩法、版本与证据更新

## 已经看到的游戏

竖屏俯视球场，双方各5枚圆盘球员，共用1个足球。轮到自己时拖动本方棋子选择方向和力度，松手弹射，利用棋子间的撞击把足球送进球门。竞技场是双方同时在线、轮流出手的对战。

| 内容 | 证据与时间 | 能确认到哪里 |
|---|---|---|
| 5对5圆盘阵容 | 2016宣传图；本包assets与references | 可确认可见布局；阵型不止一种 |
| 轮流回合的在线对战 | 2018-04-20官方来源发行稿，17173转载 | 说明2018 H5玩法；不保证早期手游每条规则相同 |
| 弧线球 | 2016官方商店日志、官方回复；海外CURVE界面 | 确认存在；作用于棋子还是足球尚未逐帧确定 |
| 完全球过线才进球 | TapTap官方V1.3.3历史日志，2016-12-13 | 这是明确规则，不使用球心过线作为替代 |
| “三球定胜负” | 官方宣传文案 | 不能据此确定所有胜负与超时细节 |
| 概率技能与属性 | 两版card、card_attr、skill原值；2016—2017官方更新 | 配置可直接查02目录；效果枚举、计数与执行时序尚有缺口 |
| 训练、友谊赛等 | V1.4.0官方更新公告，2017-01 | 内容分版本加入，不把后加功能写成封测已有 |
