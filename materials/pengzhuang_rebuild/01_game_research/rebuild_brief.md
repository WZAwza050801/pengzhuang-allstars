# 第一版复刻怎么开工

目标：把“瞄准一枚棋子 → 弹出去 → 球与人互相撞开 → 对手接着打”这段体验做回来，让 Wang 能用实际游玩校正手感。

这是实现建议。所有暂定规则都应可配置；不要把建议参数标成原版数据。原版使用过 Cocos Creator 是历史事实，但恢复体验不要求拿到同一引擎或原工程。

## 一局比赛的流程

1. 载入两队各 5 人的布局、一个足球与上下球门。
2. 回合开始，处理持续状态与可触发技能；基础原型先不加随机技能。
3. 操作方选一个本方棋子，拖动瞄准，显示方向和力度。
4. 释放后禁用新的出手，计算圆盘之间、圆盘与足球、物体与边墙／门柱的碰撞。
5. 若足球整体合法进入球门，立即记分，避免同一运动重复计分。否则等待本次运动结束。
6. 运动结束后更新状态、交给下一方；额外行动等技能在加入后显式处理。
7. 满足所选结算规则则结束，否则继续。原型可暂用先到 3 球；原版宣传“三球定胜负”的准确含义仍需录像确认。

第 4—6 步是建议的可实现流程，不是已经观测到的原版代码顺序。特别要核实：进球是否立即终止剩余运动、所有棋子是否重新站位，以及谁开下一球。

## 按什么顺序做

| 阶段 | 做到什么 | 完成的判断 |
|---|---|---|
| A：可玩的比赛 | 5 对 5、选人、拖放、直线弹射、边墙反弹、门柱、进球、换手、本地双人 | 两人能连续玩完一局；没有球还在动就二次出手、穿墙或重复得分 |
| B：手感校准 | 把力度、惯性、圆盘质量、弹性与停下条件放在一个调参面板里 | 同一出手可重放；调一个参数能看出对应差异；Wang 能指出哪处像或不像 |
| C：恢复特点 | 明确弧线操作和作用对象；加入 3—5 名差异清楚的原创球员与少量技能 | 能解释弧线怎样绕过障碍；每个技能都能稳定触发并验证效果 |
| D：长期玩法 | 阵容编辑、签约、升级、训练关卡、本地保存 | 更换阵容确实影响下一局；养成不遮住核心对战问题 |
| E：网络对战 | 在线房间、合法出手校验、权威结算、掉线恢复 | 两端比分、回合、位置一致；断线后能回到同一局 |

不预先承诺工期。A—C 的工作量主要取决于要做到“能玩”还是“手感接近”，以及能否获得录像或旧设备上的可用版本。

## 怎么校准手感，而不是凭感觉乱调

固定一个初始局面，每次只改一个参数。建议留下以下对照：

- **空场短推／满力**：记录移动距离、停下所需时间；确定力度映射和摩擦。
- **正面撞球**：记录球与球员碰后的速度比；确定质量与弹性。
- **斜撞球／连续碰撞**：确认角度变化、球员相互推开和贴边行为。
- **侧墙反弹**：记录反射角与速度损失；区分直线边墙和特殊角落装置。
- **门柱擦边与高速入门**：检查漏碰撞和误计分。
- **弧线绕人**：只有确认原版控制对象后，才拟合曲率、持续时间与强度。

无录像时，这些对照只能构成原型自己的标准，不能证明与原版一致。截图上的红色圆圈可能是瞄准显示、范围提示或技能表现，先保留疑问。

## 实现需要守住的几个细节

- 用固定时间步计算物理，例如 1/120 秒；绘制帧率独立。120 Hz 是建议值，不是原版信息。
- 棋子和足球分别有半径、质量、阻力；不要因为外观相近就设为完全一样。
- 门柱要有实际碰撞体；球门开口内不能保留一整段端线墙。
- 以“足球整体过线且在有效门口内”为进球基础。高速球应用连续检测或足够细的子步，避免一帧跨过门柱。
- 所有运动物体低于阈值并维持一小段时间后才能换手；移出场的球员等特殊状态另行处理。
- 随机技能采用可记录的随机种子，保存出手前状态和出手参数，便于重放。不要每个客户端各自随机。
- 最初数据可以只包含 Match、Team、Player、Ball、Shot、Skill、TurnState；职责清楚再拆，暂时不需要账户、付费和赛季后台。
- 真的联机时，建议服务器验证出手并负责最终状态。物理结果是否可跨设备确定，需要实际验证；不要直接假设两端独立计算就永不分歧。

## 第一轮必须补的证据

| 缺口 | 为什么影响复刻 | 最有用的补充 |
|---|---|---|
| 弧线完整手势和作用对象 | 决定操作和物理模型 | 含手指／鼠标动作的教学录像 |
| 回合时限、总时长、胜负和平局 | 决定整局节奏 | 一局从开球到结算的连续录像 |
| 进球后重置和开球 | 改变攻守策略 | 至少两个进球后的连续画面 |
| 惯性、质量、摩擦、最大力度 | 决定最核心的手感 | 可逐帧分析的直推、撞球、撞墙片段 |
| 技能完整效果和触发范围 | 仅有概率还不能实现原技能 | 球员详情截图＋技能实战片段 |
| 角落弹簧等机关是否常驻 | 可能是特殊场地或测试版差异 | 同一版本多场比赛记录 |

## 可以直接交给开发者的任务说明

请读取本包 facts.json、sources.json、image_sources.json 和 prototype_settings.json。先实现竖屏、本地双人、两队各 5 枚圆盘球员的撞球足球。第一阶段只做选人、拖放、直线物理、反弹、门柱、全球过线记分与回合切换。把所有未确认规则显式列为配置，用简单原创头像。提供暂停、重置、出手重放和调参面板。不要宣称参数来自原版，不要擅自补齐未知球员属性，也不要先搭抽卡或账号后台。基础手感经试玩确认后再加入弧线和少量技能。
