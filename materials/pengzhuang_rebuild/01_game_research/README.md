# 《碰撞全明星》复刻资料包

核查日期：2026-11-14（北京时间）。这是前期研究与实现建议，不是原版源码或可运行游戏。

## 从哪里看起

1. 打开 `research.html`：图文资料册，图片已内嵌，可离线查看；可按版本筛选图片并点击放大。
2. 看 `rebuild_brief.md`：第一版原型的范围、实现顺序、手感校准与验收条件。
3. 看 `facts.json`、`sources.json`：每条结论的证据、日期与可信度。
4. `assets/` 保存本次实际下载的 19 张历史图片；`image_sources.json` 记录来源、原始地址、尺寸与 SHA-256。大多是包含游戏画面的宣传合成图，并非原始无装饰截图。
5. `prototype_settings.json` 是可调整的起始参数，全部明确标注为复刻建议，不是从原版恢复的数据。
6. `video_reference.json` 保存视频链接、核实到的元数据与观察限制。

## 最重要的判断

- 足以开始做一版 5 对 5、轮流弹射的单机双人原型。
- 原版区别于普通撞球足球的关键包括弧线、球员差异与技能；这些应逐步恢复。
- 尚不能声称精准还原：原版摩擦、速度、弧线计算、回合时限、完整技能表和结算条件仍缺少证据。
- 2016 独立手游、2017 海外宣传素材、2018 H5／微信小游戏资料应分开使用。
- “因为足球明星版权问题下架”尚未核实；TapTap 当前标注已停服，但未给出原因或准确停服日期。

原图仅作为历史研究参考保存，原游戏与图片权利属于相应权利人。建议原型先用自制头像与界面素材。资料包不包含安装包、原版程序、声音或商业使用授权。
