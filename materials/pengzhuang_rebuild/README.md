## 使用时最重要的三条

1. **原值保持原样。** 重量、力度、心理、弧度、精准是游戏属性点，尚未恢复实际物理公式。不能把重量70直接当70kg、弧度70直接当70度。20张卡牌基础值与1级值不同，冲突单列。
2. **联机只有服务器判结果。** 浏览器上传“我用谁、朝哪、几成力”，服务器计算碰撞、技能和进球；两端显示同一份结果。前端预览与自动调参导入同一份物理代码，但客户端预览不作为比分依据。
3. **少调参数靠可重复测量。** 让开发AI先交付自动校准脚本、轨迹回放和差异报告，再加完整球员技能。没有实况测量时，只能拟合一套舒服的复刻手感，不能声称已经还原原版物理。

## 当前建议的实现

前端：**Vite＋TypeScript＋PixiJS 8绘制球场，DOM/CSS绘制大厅和卡牌界面**。物理：**Planck.js**独立共享。联机：**Node.js＋Colyseus＋WebSocket**。存档：少量好友场景用单实例SQLite，数据库放持久化磁盘。

这是工程建议，依据见各技术目录及官方文档来源；没有在本资料包中完成依赖安装、兼容性联调或性能实测。实施时须锁定兼容版本和lockfile。
