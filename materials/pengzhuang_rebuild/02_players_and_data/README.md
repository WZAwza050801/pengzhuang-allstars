- 108条人物线索：106位从卡表直接配对，另有1张未关联卡表的小罗候选，以及仅在语言表出现的卡队／法比奥·卡纳瓦罗。

## 建议阅读顺序

1. `index.html`：离线人物与数据总册，每个人展开可看两版基础值、1级值和技能关联。
2. `pengzhuang_reference.xlsx`：人物索引、卡牌、等级、技能、版本变化、数值冲突、字段说明与来源目录。
3. `reference_tables/版本/`：原始字段字符串JSON与TSV。空字符串不是0；分号列表保留顺序。人物小传未作为数值表收录。
4. `catalog.json`、`card_records.json`、`level_records.json`、`skill_records.json`、`skill_links.json`：供程序读取的整理表。
5. `portraits/版本/`：独立透明PNG；`source_atlases/`是原始图集。
6. `generation_jobs.jsonl`：106位已关联人物的生图任务；额外候选头像单列在`pending_generation_jobs.json`。

## 不能忽略的差异

- **20条卡牌基础值与同卡1级属性不同**：两组值并排保留在`parameter_conflicts.json`和工作簿“参数冲突”。其中一些后加入卡牌的card值很相近，可能含占位值，但运行时取哪张表尚未确认。
- **早期齐祖未关联**：1.2.0等级表有90001的10行数据，卡表和头像中却没有对应记录。已保留，未据此认定当时已上线。
- **小罗候选**：新增找到`head_4001_40109`；头像和语言表中的Ronaldinho／小罗相符，但无卡表关联。用户尚未确认；没有编造任何属性。
- **卡队仅有名字**：语言键`PlayerName_Fabio_Cannavaro`对应卡队；没有找到关联头像、卡牌或属性，保持空缺。
- **耳帝原名冲突**：原表写Nicolas Burdisso，俱乐部却填加拉塔萨雷。该俱乐部官方2014-02-03公告写Guillermo Enio Burdisso。两者作为独立证据保留，显示名未自动纠正。

## 将来调参时怎样使用

- weight/power/mind/radian/precision是源表属性点；对应物理单位、公式与作用范围尚未恢复。
- `radian=70`不能直接当70弧度或70度；`weight=70`不能直接当70kg；精准值也不是已证实的命中概率。
- 源值保持原样，把将来拟合出的“属性点→实际速度/质量/曲率”映射另建配置，记录依据和测量结果。
- 技能triggerPerList是列表，不直接相乘成一个概率。duration保留原始计数，与中文描述对照，不能直接改成秒。
- 训练坐标和比赛阵型坐标格式不同，原点、区域缩放与坐标变换尚未验证。
- 文件内数据可能被热更新或服务端覆盖，不声称这里是停服前的最终全集。
